# Game context (manual & walkthrough)

Reference material for later phases — shops, secrets, item progression, dungeon layouts, and “how the game is meant to be played.” Not used by extractors or the engine at runtime.

Both files below are **gitignored**. Keep local copies; do not commit them.

| File | Use for |
|------|---------|
| `manual.pdf` | Official item/dungeon/overworld framing; UI copy; intended controls |
| `walkthrough.txt` | Sequence checks, secret locations, softlock avoidance when building Phases 6–10 |

Prefer ROM-extracted data and the behavior oracle when they disagree with a walkthrough. Use these docs to fill gaps and validate playability.
